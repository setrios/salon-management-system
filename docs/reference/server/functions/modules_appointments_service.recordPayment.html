      R27 — record the payment of a completed appointment (REQ-F-021, D12).

      The order of the two 409s (N5). The record's state is read first: an appointment that is not completed answers not-completed, whatever else is true of it. Only a completed record reaches the insert, where D12's unique constraint answers already-recorded — the constraint rather than a read-then-write, so two simultaneous requests cannot both pass a check and both insert.

      The appointment row is not written (N6): recording money is not a change to the booking, so its status and updatedAt stay as they were.

      now is the application's clock and becomes the payment's recordedAt.
