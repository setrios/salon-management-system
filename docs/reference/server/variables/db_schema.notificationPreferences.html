    Notification preferences (REQ-F-016, REQ-F-023, REQ-F-026; S4.1, I1–I2).

    One row per combination the caller has toggled: the table is a sparse override, and a missing row means enabled: true (I2). The principal is a masters row — the administrator is one, with role = 'admin' (REQ-F-017) — so one table serves both roles.

    The unique index is what makes M6 an upsert rather than a second row: the operation changes exactly one combination (REQ-F-026), and a duplicate would make "the caller's setting" ambiguous.
