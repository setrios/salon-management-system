## 1. What this gate decides

The plan fixes one exit gate for the three implementation stages of S2
(SMS-25, SMS-26, SMS-27) and six criteria that a gate record must show (§8.3).
The criteria are worded as commands and file paths, not judgements, so this
record answers each one with the thing it names. Three things it does **not**
decide, and says so here rather than by omission:

- **Validation is not part of the six criteria.** Plan §10 places it in one
  signed record at step 7. G2 is a verification gate; it neither claims
  validation nor substitutes for it (§5a).
- **The addendum is not selected here.** Plan §8.1 and D-13 place the choice
  after the base implementation is stable and before verification. Register
  row 10 names the candidate; G2 does not choose it (§5b).
- **The R21/R22 erratum is a correction of fact, not a decision.** The signed
  SMS-27 gate, `runs-07` and `state.ts` named R22 for `updateAppointmentAdmin`;
  `resource-model.md:261–263` gives R21. The four places are corrected in a
  separate `docs:` commit, and the signed gate carries an erratum note (§5c).
