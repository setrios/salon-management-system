## 1. What happened

| # | Step of the README | What happened | Why |
|---|---|---|---|
| F11 | `npx drizzle-kit migrate` | "Using 'pg' driver for database querying", then nothing; the server then failed every query on `masters` | `npm start` loads `.env` (`--env-file-if-exists=.env`), drizzle-kit does not. `drizzle.config.ts` read `process.env.DATABASE_URL ?? ''`, got `''`, and drizzle-kit gave up without an error |
| F13 | `psql -c "INSERT … VALUES (…, '<hash>', …);"` | `INSERT 0 1`, but the administrator could not sign in | the hash `scrypt$16384$8$1$…` sits inside the shell's double quotes, which expand `$16384`, `$8`, `$1`, `$oLHz…` to empty strings; a broken hash is stored without any error |

Both failures were silent, which is what made them expensive: each looked
like success until a later step.

## 2. The tests

| Case | Asserts | Red run |
|---|---|---|
| E1 | with no `DATABASE_URL` in the environment and one in `./.env`, `drizzle.config.ts` uses the file's | `expected '' to be 'postgres://from-env-file/salon'` — **exactly F11** |
| E2 | a value in the environment wins over `.env` | passes — the rule `npm start` follows, to be kept |
| E3 | with neither, loading the config fails with a message naming `DATABASE_URL` | `promise resolved "''" instead of rejecting` — the silence of F11 |
| C1 | `node scripts/create-admin.mjs --username owner --full-name "Salon Owner"` with `ADMIN_PASSWORD='pa$$w0rd$1 with $HOME'` creates the administrator; A1 signs in with that password, `role: admin` | `Cannot find module …/scripts/create-admin.mjs` |
| C2 | a second run refuses ("administrator already exists"); still one administrator (REQ-F-017) | same |
| C3 | no `--username`: exit with the usage, nothing written | same |

E1–E3 load the configuration in a temporary directory with their own `.env`;
no developer's `.env` is read. C1 is the F13 case in its worst form: a password
full of `$`, passed through the environment, never through a shell string.

## 3. Planned fix

| # | Change |
|---|---|
| F11 | `drizzle.config.ts`: when `DATABASE_URL` is not in the environment and `./.env` exists, load it (`process.loadEnvFile`, which never overrides a set variable); when there is still none, throw `DATABASE_URL is not set …`. The README's command stays `npx drizzle-kit migrate`, and gains an npm alias `npm run db:migrate` |
| F13 | `scripts/create-admin.mjs` (`npm run create-admin -- --username … --full-name …`): reads the password from `ADMIN_PASSWORD` or asks for it, hashes it with the server's own `hashPassword` (`src/modules/auth/password.ts`, imported directly — Node 24 runs TypeScript), inserts the row with a parameterised query, refuses a second administrator and a taken username. No hash ever passes through a shell |
| README | SMS-62 rewrites "Quick start" and "The first administrator" around the two commands; the developer re-runs it from a clean clone in SMS-64 |
