## 4. The defect the linter found

`src/modules/reports/period.ts` marked a repeated query parameter with the
string `'repeated'`, so `?period=repeated` was answered 400 instead of the 422
that decision Q1 requires for any unknown preset. It changes behaviour, so it
was not fixed inside this refactor: it got its own ticket (SMS-69), a failing
test, its own TEST-GATE (GO, signed) and a `feat:` fix. This gate covers the
behaviour-neutral commits only.
