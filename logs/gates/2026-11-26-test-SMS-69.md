## 1. The defect

`readOne()` returns `string | undefined | 'repeated'`. The third member is a
string literal, so it is absorbed by `string`: the type says nothing more than
`string | undefined`, and at run time the marker for "this parameter was given
twice" is the same value as a client who sent the word `repeated`.

```ts
if (Array.isArray(value)) return 'repeated';   // ?period=day&period=week
...
return value;                                  // ?period=repeated  → also 'repeated'
```

`resolvePeriod()` then answers both with `{ kind: 'malformed' }` → 400.

## 2. What the specification says

| Source | Statement |
|---|---|
| REQ-F-022 | a report period is a preset or a custom range |
| `openapi.yaml` R28/R29 | `period` is `enum: [day, week, month]`; 400 and 422 are both declared |
| `error-model.md` §3 | `INVALID_PERIOD` (422) is the code for a period that cannot be used |
| TEST-GATE SMS-35, decision **Q1** | "An unrecognised `period` value is 422 `INVALID_PERIOD`, not 400" — asserted by R4 (`period=quarter`) and R8 (`period=year`) |

So the word `repeated` is an unrecognised preset like `quarter`, and the answer
is 422. The defect is a deviation from an approved decision, not a gap in the
specification: no addendum and no contract change are needed.

## 5. Planned fix

Replace the string sentinel in `readOne()` by a value that cannot collide with
a query string (a tagged result), so that only a parameter given more than once,
or given as a non-string, is malformed. No other file changes.
