## 1. What is being approved

The implementation phase plan: stages S1.0–S5.5, the refactoring pass, one
addendum with a repeated SDD cycle, and the final verification, validation and
checkpoint. The approved OpenAPI contract is the external interface and is not
edited by this phase. Requirement changes go through a clarification row or an
addendum, never through code.

## 4. Execution policy

`CLAUDE.md` forbids the coding agent from installing dependencies and from any
non-idempotent git operation. This is not an exception to that policy — it is the
intended split:

| Action | Human | Agent |
|---|:---:|:---:|
| Create or edit files in the working directory | — | ✓ |
| `npm install`, adding a dependency | ✓ | — |
| `docker compose up -d postgres` | ✓ | — |
| `git add`, `git commit`, branch operations | ✓ | — |
| Read-only git (`log`, `diff`, `status`, `cat-file`) | ✓ | ✓ |
| `tsc --noEmit`, `vitest run`, `redocly lint`, contract verification | — | ✓ |
| Gate decisions, validation sign-off | ✓ | — |

## 7. Notes and corrections

Two review findings from the advisory review were re-examined against the
artefacts and resolved as follows.

- **E-1 (was: change the 201 schema to `AppointmentAdmin`).** Withdrawn. Changing
  the schema would remove the client link an administrator-created appointment
  must still produce. The inconsistency is recorded as CL-06 and the contract is
  left alone.
- **E-2 (was: no plan/contract mismatch).** The original advisory position was
  wrong. `logs/2026-10-26-api-design-plan.md:127` does contain `AppointmentPage`,
  which has no schema in the contract. The correction is recorded as CL-07:
  `openapi.yaml` and `resource-model.md` are authoritative, and the committed
  design plan is not retroactively edited.

Two working corrections were also applied to the plan before approval:

- The clarification register was returned to `CLOSED` (D-15). Setting it to
  `OPEN` would have made three clarification rows block the first TEST-GATE,
  which the register's own rule does not require.
- Stage S1.0 received ticket SMS-44 and the addendum moved to SMS-45 (D-16), so
  that every stage has a manifest entry for the causal-independence check.
